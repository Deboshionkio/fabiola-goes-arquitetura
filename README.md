# Fabíola Góes Arquitetura — Website Oficial

Website moderno, responsivo e interativo desenvolvido para o escritório **Fabíola Góes Arquitetura** em Belém – PA.

Especializado em Projetos Arquitetônicos Residenciais e Comerciais, Licenciamento de Obras, Habite-se e Regularização de Imóveis.

---

## 🚀 Como Publicar na Vercel em 1 Minuto

1. Suba esta pasta para um repositório no seu GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: site fabiola goes arquitetura completo"
   git branch -M main
   git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   git push -u origin main
   ```
2. Acesse [vercel.com](https://vercel.com) e clique em **"Add New Project"** -> **"Import Git Repository"**;
3. Selecione o repositório e clique em **"Deploy"** (não precisa alterar nenhuma configuração, o `vercel.json` já está pronto);
4. O link público `.vercel.app` será gerado automaticamente!

## 📁 Estrutura do Projeto

* `index.html`: Estrutura principal da página com todas as seções e âncoras ajustadas.
* `css/style.css`: Estilização arquitetônica minimalista, efeito glassmorphism e responsividade.
* `js/main.js`: Lógica interativa (Quiz de Regularização, Calculador de Orçamento Guiado, Slider Antes/Depois, Acordeões e Painel de Customização).
* `assets/`: Imagens, logos e fotos originais da arquiteta.
* `vercel.json`: Otimizações de cache e segurança para a Vercel.

## ⚡ Principais Recursos do Site

1. **Hero de Alta Conversão:** Estatísticas de mercado (15+ anos, nota 5.0 Google, Belém & Online).
2. **Serviços Sanfonados:** Projeto, Regularização, Licenciamento, Cursos e Palestras.
3. **Portfólio com Filtro + Antes/Depois:** Slider interativo para visualização de reformas.
4. **Quiz de Diagnóstico (1 min):** 3 perguntas rápidas com veredito automático e envio no WhatsApp.
5. **Orçamento Guiado:** Wizard interativo que atualiza o mockup do WhatsApp em tempo real.
6. **Como Funciona & Depoimentos Reais:** 4 etapas claras e avaliações do Google.
7. **Área para Profissionais:** Inscrições e agendamentos de consultoria/cursos.
8. **Sobre a Arquiteta:** Credenciais reais FAU/UFPA e mais de 12 anos no setor público de projetos legais.
9. **Painel Flutuante:** Controle interativo de seções no canto da tela para testes com a cliente.
